# My Nota — Post-it Notes (Chrome Extension)

จดโน้ตแบบบล็อกสไตล์ Notion บนกระดาษ Post-it · รองรับทุกภาษา · บันทึกโค้ดพร้อมไฮไลต์ · ซิงก์ทุกเครื่อง

## ติดตั้ง (ทำแบบเดียวกันทุกเครื่อง)
1. เปิด `chrome://extensions`
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** → เลือกโฟลเดอร์นี้ (`My Nota`)
4. ปักหมุดไอคอน 📒 ไว้ที่แถบเครื่องมือ (หรือกด `Alt+N`)

> Extension ID ถูกล็อกไว้ด้วย `key` ใน manifest = `ifhjgglokfbjbcmehnicgkonoifkkboh`
> ทุกเครื่องจึงได้ ID เดียวกัน → ใช้ข้อมูลซิงก์ชุดเดียวกัน **ห้ามลบ `key` ออกจาก manifest.json**

> ⚠️ **ห้ามกด Remove Extension** — ทดสอบแล้วว่าการ Remove บนเครื่องใดเครื่องหนึ่ง จะลบโน้ตบน**ทุกเครื่อง**ที่ซิงก์กันอยู่
> อัปเดตโค้ดให้แตกไฟล์ทับโฟลเดอร์เดิมแล้วกด **รีโหลด** · ถ้าไม่อยากใช้ชั่วคราวให้กด**ปิดสวิตช์**แทน
> ส่งออกโน้ต (เมนู ⋮ → ส่งออก .json) เก็บไว้เป็นระยะเสมอ

## การซิงก์ข้ามเครื่อง
ใช้ **Chrome Sync** (`chrome.storage.sync`) — ไม่ต้องมีเซิร์ฟเวอร์
- ทุกเครื่องต้องล็อกอิน Chrome ด้วย **บัญชี Google เดียวกัน**
- เปิด Sync และให้ตัวเลือก **Extensions** เปิดอยู่ (`chrome://settings/syncSetup/advanced`)
- โน้ตใหม่จะขึ้นที่เครื่องอื่นภายในไม่กี่วินาทีถึงประมาณ 1 นาที

**ข้อจำกัด:** Chrome Sync ให้พื้นที่รวม **100 KB** (โน้ตถูกบีบอัดก่อนเก็บ จึงจุได้ประมาณ 200–300 KB ของข้อความ)
ดูพื้นที่ที่ใช้ได้จากแถบด้านล่าง ถ้าพื้นที่เต็ม โน้ตยังถูกเก็บไว้ในเครื่องนั้น และจะซิงก์ให้เองเมื่อมีพื้นที่ว่าง
สำรองข้อมูลได้ที่เมนู ⋮ → ส่งออก / นำเข้า (.json)

## วิธีใช้
| ทำอะไร | วิธี |
|---|---|
| เปลี่ยนสีโน้ต | กดวงกลมสีด้านบน หรือปุ่มจานสีเพื่อดู 18 สี / กำหนดสีเอง (แถบ สี-สด-สว่าง หรือพิมพ์รหัส #hex) |
| ตัวหนา / ตัวเอียง | `Ctrl+B` / `Ctrl+I` หรือปุ่ม **B** / *I* ด้านล่าง |
| เลือกประเภทบล็อก | พิมพ์ `/` ในบรรทัดว่าง |
| หัวข้อ | `# ` หรือ `## ` |
| รายการ / ลำดับเลข | `- ` / `1. ` |
| To-do | `[] ` |
| อ้างอิง | `> ` |
| บล็อกโค้ด | ` ``` ` หรือกดปุ่ม **</> Code** |
| เส้นคั่น | `---` |
| วาดรูป | ปุ่ม 🎨 หรือ `/draw` — เลือกสี 7 สี, ขนาดแปรง 4 ขนาด, ยางลบ, ย้อนกลับ (`Ctrl+Z`), ปรับความสูง ↕, ล้าง |
| ออกจากบล็อกโค้ด | `Ctrl+Enter` หรือ ↓ ที่ท้ายโค้ด |
| ย่อหน้าในโค้ด | `Tab` / `Shift+Tab` |
| ย้าย / ลบ / ทำสำเนาบล็อก | ปุ่ม ⋮⋮ ด้านซ้ายของบล็อก |
| กลับหน้ารวม | `Esc` |

บล็อกโค้ดไฮไลต์ได้ 25 ภาษา (เดาภาษาให้อัตโนมัติเมื่อวางโค้ด):
- **Web:** HTML (รวม `<style>` / `<script>` ข้างใน), CSS, SCSS, JavaScript, TypeScript, PHP, JSON, XML/SVG
- **ภาษาทั่วไป:** Python, C, C++, C#, Java, Kotlin, Swift, Go, Rust, Dart/Flutter, Ruby, Lua
- **สคริปต์ & ข้อมูล:** Bash, PowerShell, SQL, YAML, Markdown

## โครงสร้างไฟล์
```
manifest.json     MV3 manifest (ล็อก ID ด้วย key)
popup.html        UI (ใช้ทั้ง popup / side panel / แท็บ)
styles.css        ธีม Post-it, กว้าง 400px
fonts/            Poppins (อังกฤษ) + Noto Sans Thai (ไทย) แบบฝังในตัว ใช้ได้แม้ออฟไลน์ (SIL OFL)
js/storage.js     ซิงก์: บีบอัด + หั่น chunk ลง chrome.storage.sync, เก็บ draft ใน storage.local
js/highlight.js   ตัวไฮไลต์โค้ด (ไม่พึ่ง library ภายนอก)
js/icons.js       ชุดไอคอนเส้น (SVG) ที่ใช้ทั้งแอป
js/colors.js      สีโน้ต 18 สี + สีกำหนดเอง, เลือกสีตัวหนังสืออัตโนมัติตามความเข้มพื้นหลัง
js/draw.js        บล็อกวาดรูป (เก็บเป็นเส้น vector เพื่อประหยัดพื้นที่ซิงก์)
js/app.js         ตัวแก้ไขแบบบล็อก, หน้ารวมโน้ต, ค้นหา, นำเข้า/ส่งออก
background.js     ซิงก์ draft ที่ค้างหลังปิด popup
```
